# Smart Home Care (web + ESP32)
- index.html, style.css, script.js : web Anda (tetap), robot.js : simulasi + koneksi ESP32
- assets/ : ilustrasi robot  |  esp32/ : kode Arduino
Buka index.html langsung di browser. Mode "ESP32 Asli" butuh IP ESP32 dan halaman dibuka lewat file lokal atau http:// (bukan https://).
